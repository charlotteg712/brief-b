Charlotte App – Mac Setup Guide

One-time setup on a Mac. Takes about 10–15 minutes.

  1. GitHub account: You need one. Accept the invitation to the repository (check your e-mail).
  2. Open Terminal: Press Cmd+Space, type "Terminal", press Enter.
  3. Run the setup script: 
    bash ~/Downloads/setup-mac.sh https://github.com/henridecker/Charlotte-Design-Project.git
    If the file is stored somewhere else, adjust the path. Alternatively, give the file to your Claude and let it run the script.
  4. While the script runs:
    • It asks for your Mac password. Nothing appears while you type – that is normal. Press Enter afterwards.
    • A dialog for the Xcode Command Line Tools may open. Confirm it and wait until the installation has finished.
    • During git clone you may be asked to sign in to GitHub. This requires a Personal Access Token; a normal password no longer works.
    • The script only installs what is missing: Homebrew, git, git-lfs, Node.js and pnpm. Then it clones the project to ~/Charlotte-App and installs the dependencies.
  5. Start the app: In Finder, open the folder Charlotte-App and double-click start.command. The browser opens automatically.
    • The first time, macOS may block the file. In that case: right-click → "Open" → confirm.
  6. Quit the app: Close the Terminal window.
